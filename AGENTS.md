# ai-coach

Правила ведения docs/ROADMAP.md, docs/BACKLOG.md, docs/handoff.md, docs/done/ и гигиены репо — @docs/RULES.md

Общие практики проектов — @~/projects/semia-kabanov/pravila/COMMON.md

## Местные правила

- `docs/pipeline.md` — журнал партий, строка на партию: проекту нужна сводка этапов в одном файле (решение Влада
  2026-10-26).
- Новая или изменённая функция тренера (команда CLI, MCP-инструмент, скил, вопрос чек-ина, шкала) — правка
  `.claude/agents/coach-help.md` и `coach-help/` в том же шаге; план шага без пункта «Справка» неполный; полноту
  имён держит `tests/test_skills_help.py` (план Н14 «Правило», принят Владом 2026-10-31).
- Строки allow `Bash(uv run coach …)` в `.claude/settings.json` добавляет Влад, не кабан: кабану классификатор
  запрещает менять собственные настройки. Кабан ставит в план пункт «Вне репо: Влад добавляет строку X»
  (решение Влада 2026-11-01, план Н12 «Решения»).
- Отчёты тренера: в начале шага и при переборе ROADMAP технический агент выполняет
  `uv run coach report list`; открытый отчёт — пункт BACKLOG своими словами, без значений и дат самочувствия; затем
  `uv run coach report done <id> --backlog <N>` (или `--drop`, причина — в чате) (решение Влада 2026-11-24, план Н34 «Решения», Р9).
- Файл справки или текст роли тренера (`.claude/agents/*.md`) с запасом до лимита размера меньше 200 Б — шаг, который его правит, сам выносит часть текста
  в боковой файл, не дожидаясь красного теста лимита (решение Влада 2026-11-14, plan-p11.md «Встройка находок»,
  Р3; BACKLOG 108).
- Личные значения Влада (вес, пульс, HRV, сон, стресс, оценки самочувствия, расчёты от них) в отслеживаемые файлы не
  пишутся: в документах — слова, в тестах и сценариях — выдуманные числа с пометкой «числа выдуманные»; замер на живой
  базе — в документ только счёт дней, вывод со значениями — в scratchpad или `spikes/out/`. Держат
  `tests/test_docs_personal.py` и `make personal` (решение Влада 2026-11-27, plan-g2.md «Решения», Р5, Р6).
- Карточка `docs/done/`: исключение из «тело без правок» (`docs/RULES.md`) — личное значение в теле карточки заменяется
  словами (решение Влада 2026-11-27, plan-g2.md «Решения», Р3).
