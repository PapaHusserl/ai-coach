- Подписка Claude: Pro ~$20/мес хватает на эксплуатацию тренера (~1–1,5M токенов входа/мес). На время разработки конвейером кабанов, вероятно, Max 5x ~$100, после MVP — откат на Pro. Цены не сверены → https://claude.com/pricing.
- Garmin Connect+, хостинг, библиотеки, Claude API — $0.

## Скрытые риски
1. LLM в Python-коде (например, `coach food` парсит КБЖУ) = API-ключ и платные токены вне подписки.
2. Часть метрик FR970 может оказаться за пейволлом Connect+ — проверить на спайке.
3. Не подключать платные нутриентные API (Nutritionix, Edamam).
4. mutmut гонять фоном вне агента, сессия только читает отчёт.

## Как не выжечь лимит
- MCP отдаёт только агрегаты, без raw_json; жёсткий лимит строк/размера ответа.
- Один `get_morning_snapshot` вместо 6 мелких вызовов.
- Скиллы ≤1–2k токенов, методички — в отдельных файлах; минимальный проектный CLAUDE.md.
- Модели: morning/food — Sonnet/Haiku, plan — Sonnet, Opus по запросу (`model:` во frontmatter — не проверено).
- Каждая команда — новая сессия или после /clear.
- Еду копить текстом через CLI, /coach-food раз в день пачкой (в 2–3 раза дешевле, без мгновенного фидбека).
