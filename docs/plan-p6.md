## Суть

В анкете чек-ина пульта над полями «Работа, ч / Хобби, ч / Отдых, ч» появляется строка с часами экрана за день пункта
и кнопка «подставить»: нажал — числа встают в поля «Работа» и «Хобби», дальше правятся руками и уходят обычным
«Сохранить». Пока не нажал — поля пустые (решение Влада, «Решения» п. 1). Источник числа — тот же, что у
`coach screen` и скила `coach-evening`: ActivityWatch через `read_screen` (`workload/screen.py:186`), категории
`screen_work_hours` и `screen_hobby_hours`. У «Отдыха» подсказки нет: экран его не меряет.

**Правило** (первый пункт аппрува, при Р1 = 1): было — `GET_VIEWS` из семи видов, каждый читает только базу
(`web/server.py:132–140`: `/api/day`, `/api/week`, `/api/pantry`, `/api/todo`, `/api/meeting`, `/api/state`,
`/api/sync`) → станет — восьмой вид `"/api/screen": screen_view`: GET читает локальный aw-server (`config.screen.url`
из `workload.toml`) и в базу не пишет. Правило «пульт пишет в базу только POST из `POST_ROUTES`»
(`server.py:1–5`) остаётся. При Р1 = 2 правило не меняется: число берётся из `day_counters`.
**Поведение:** меняется только анкета чек-ина пульта (строка и кнопка). Запись чек-ина (`web/marks.py:97 _checkin`),
`coach screen`, `coach sync`, скил `coach-evening`, MCP — без изменений. Правило окна v2.9 (ROADMAP «Сейчас») цело:
`load/*` не трогается, записи не переписываются, ручные часы пишутся, как и сейчас, только по «Сохранить».
**Вне репо:** нет. Новых команд CLI нет — строк allow в `.claude/settings.json` не нужно. Чтобы строка показала
числа, на компьютере с пультом должен работать ActivityWatch и быть секция `[screen]` в
`~/.config/ai-coach/workload.toml` (сейчас есть: `uv run coach screen` 2026-11-13 ответил строкой с часами).

## Развилки

Все — видимое пользователю или архитектура; выбор за Владом. Макета нет («Что уже есть»), вид — по прецедентам
шапки пульта.

**Р1. Откуда число и насколько оно свежее.**
(1) Живое чтение: новый `GET /api/screen?date=` спрашивает ActivityWatch в момент раскрытия окна чек-ина; в базу не
пишет. Число — «на сейчас», как у скила вечера после `coach screen`. Цена: первый GET пульта, который ходит не в
базу (локальный HTTP); если ActivityWatch завис — строка ждёт до 30 с (`TIMEOUT`), остальная анкета работает.
(2) Только база: `screen_work_hours` / `screen_hobby_hours` из `day_counters` в ответе `/api/day`. Правило не
меняется, кода меньше (~190 против ~265). Цена: число на момент последнего `coach sync` / «обновить»; вечером без
синка — утреннее, и подставится заниженное. Тогда строка должна показывать время («экран на 10:11: …»).
(3) Как (1), но ещё и пишет счётчики экрана в базу (как `coach screen`). Цена: GET начинает писать — ломает правило
`server.py:1–5`.
Рекомендую (1): ради свежего числа пункт и заведён; (2) даст кнопку, которая вечером подставляет утренние часы.

**Р2. Что в строке.**
(1) «экран: работа 4.2 ч · хобби 0.8 ч · подставить»; (2) то же и «· браузер 1.3 ч», когда браузер > 0 — как в
`coach-evening` (`SKILL.md:14`): браузер показывается для сведения, в поля не идёт; (3) подсказка у каждого поля
отдельно («Работа, ч» — «экран 4.2»), без общей строки.
Рекомендую (2): тот же состав, что вечером у тренера; неразмеченный браузер объясняет, почему работа меньше ожидаемой.
Числа — с точкой, один знак, как вес в шапке (`header-model.js:4`).

**Р3. Данных экрана нет.** Три причины: нет `[screen]` в конфиге; ActivityWatch не отвечает; за день нет событий окон.
(1) Серая строка с причиной, без кнопки: «экран: не настроен», «экран: ActivityWatch не отвечает», «экран: за день
пусто»; (2) одна строка на все случаи: «экран: нет данных»; (3) строки нет вовсе, анкета как сейчас; (4) только при
Р1 = 1: если ActivityWatch молчит — число из базы с временем («экран на 10:11: …»), иначе как (1); +~15 строк.
Рекомендую (1): с телефона иначе не понять, почему кнопки нет, а причина подсказывает действие. Пока ответ не
пришёл — «экран: …» (при Р1 = 1).

**Р4. Какое число встаёт в поле.**
(1) Как есть, два знака (4.19) — так пишет скил вечера; (2) один знак (4.2), то же число, что в строке; (3) до шага

Рекомендую (2): в поле то же, что прочитал в строке; расхождение с экраном ≤ 0,05 ч. Шаг стрелок поля (0.5) не

**Р5. Кнопка.**
(1) Одна «подставить» на оба поля; заменяет и уже набранное в «Работа» и «Хобби»; «Отдых» не трогает;
