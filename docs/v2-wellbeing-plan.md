## Что уже есть (v1, шаги 0–22)

В документах проекта (`plan.md`, `backlog.md`, `pipeline.md`, `architecture-2026-10-06.md`) про «v2» и «веллбиинг-коуча» ничего нет — это новая задача. Бэклог пуст (одна строка про порог qlty).

Тренер v1 — спортивный: Garmin-sync, цели/фазы, план недели черновиками с отправкой на часы, план/факт и нагрузка CTL/ATL, вес и еда с КБЖУ, профиль, рецепты и кладовая, спортпит, курсы витаминов/безрецептурного с красными флагами, плеер тренировки на телефон. Самочувствие — только оценка 1–5 + текст (`wellbeing_log`, `coach feel`), используется как один из порогов «плохого восстановления». Агент `.claude/agents/coach.md` (≈13,5 КБ, близко к потолку ~15 КБ из шага 20).

## Что меняется в v2 (предложение)

Центр — не тренировки, а самочувствие в целом; тренировки становятся одной из опор наряду со сном, стрессом, едой, настроением и привычками.

| Опора | v1 | v2 (предложение) |
|---|---|---|
| Самочувствие | 1–5 + текст | Чек-ин по осям: энергия, настроение, стресс, сон субъективно, боль/тело (1–5 каждая) + заметка |
| Сон | метрики Garmin | + разбор трендов, советы по гигиене сна, вечерний ритуал |
| Стресс | стресс/BB Garmin в snapshot | + короткие практики (дыхание, пауза), подбор по стрессу/BB |
| Привычки | нет | Трекер привычек (вода, шаги, экран вечером, прогулка и т.п.), серии, мягкие напоминания в разборе |
| Рефлексия | нет | Вечерний чек-ин / дневник: что было хорошо, что мешало |
| Недельный обзор | план недели тренировок | + обзор благополучия: тренды осей, связи (сон ↔ настроение ↔ нагрузка) |
| Тренировки, еда | как есть | Без изменений; тон тренера учитывает общее состояние |
| Границы | красные флаги → к врачу (8в) | + границы психологического: при признаках кризиса — к специалисту/горячей линии, без «терапии» |

Архитектурный принцип v1 сохраняется: цифры и записи — в SQLite через CLI/MCP, логика — в промптах; MCP пишет только черновики и то, что уже разрешено.

## Этапы (предварительно, каждый — по циклу «Общее для шагов 2–8»)

1. **v2.0 — груминг и решения Влада** по открытым вопросам ниже; детализация папой-кабаном; проверка по деньгам кабаном-тестем.
2. **v2.1 — чек-ин по осям:** миграция (расширение `wellbeing_log` или новая таблица), `coach feel` с осями, `get_wellbeing`, snapshot; пороги восстановления учитывают оси.
3. **v2.2 — привычки:** таблицы привычек и отметок, `coach habit add/done/list`, MCP чтение, раздел в snapshot.
4. **v2.3 — практики стресса и сна:** справочник практик (как рецепты), подбор по стрессу/BB/сну в разборе; вечерний ритуал.
5. **v2.4 — вечерний чек-ин и недельный обзор благополучия:** новый скил (например `/coach-evening`, `/coach-week-review`), тренды и связи.
6. **v2.5 — агент:** роль «веллбиинг-коуч» в промпте, вынос частей в файлы по требованию (лимит размера), границы психологического.

## Открытые вопросы к Владу

1. **Что значит «веллбиинг-коуч» для тебя?** Какие опоры главные (сон, стресс, настроение, привычки, отношения/работа, ментальное)? Может, идея уже где-то описана?
2. **Один агент или два?** Расширить `тренер` или отдельный агент (`коуч`) поверх тех же данных?
3. **Ритм:** только утренний разбор как сейчас, или добавить вечерний чек-ин? Напоминания/проактивность (cron, уведомления) нужны?
4. **Привычки:** какие трекать сразу? Свои или из Garmin (шаги, вода из Connect)?
5. **Ментальное здоровье:** насколько глубоко — только настроение/стресс или дневник, КПТ-упражнения? Границы и куда направлять при тревожных сигналах.
6. **Данные:** дневниковые записи — чувствительные; репо публичный (шаг 21) — база вне репо, но ок ли хранить свободный текст рефлексии?
7. **Модель и деньги:** Sonnet как в v1? Вечерний скил дешёвой моделью (Haiku)?
8. **Порядок этапов** и что входит в первый релиз v2.
