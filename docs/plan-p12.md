## Суть

У события появляется «форма» — именованный набор полей с типами (число, шкала 1–5, да/нет, выбор из списка) и
общий текст. Форму заводит тренер по словам Влада (MCP), событие любого вида ссылается на неё полем `survey`, пульт
под пунктом показывает поля формы (у чек-ина — вместо опросника, у остальных видов — вкладкой рядом со штатными),
ответы ложатся в базу готовыми значениями, тренер читает их MCP-инструментом — без разбора текста.
Пример Влада: «Температура и самочувствие» = «Самочувствие» (шкала) + «Температура» (число, °C).

**Правило** (первый пункт аппрува):
1. было — опросник только у чек-ина и только из пяти готовых: `if kind != "checkin": raise AgendaError(f"survey
   только у checkin, а kind={kind}.")`, `if given not in SURVEYS: raise AgendaError` (`agenda/service.py:81–84`),
   `SURVEYS = ("evening", "feel", "focus", "none", "who5")` (`:28`) → станет — `given == "form:<имя>"` активной
   формы из новой таблицы `forms` допустимо у события любого вида из `KINDS`; готовое имя из `SURVEYS` —
   по-прежнему только у `checkin`. Меняет решение П11 Р9 = 1 для форм (Р9 = 2, «Решения» п. 12).
2. было — отметки пункта: `kinds = marks_of(row["survey"]) if row["kind"] == "checkin" else
   ALLOWED.get(row["kind"])` (`web/marks.py:91`), «красное»: `return past and missing.get(kind, False)` (`:215`)
   → станет — к тем же отметкам добавляется `"form"`, если `survey` события — форма; «красное» —
   `past and (missing.get(kind, False) or <у пункта с формой нет ответа формы>)` (при Р15 = 1).
3. было — MCP пишет только черновики, КБЖУ и варианты блюд (`mcp_server/server.py:33–39`, `INSTRUCTIONS`) →
   станет — ещё и определения форм: `create_form`, `archive_form` (Р2 = 1, Р10 = 1).

**Поведение:** меняется — `create_draft_event` (значение `survey`, теперь и у не-чек-ина), `get_agenda` и
`coach event list` (значение `form:<имя>` в поле и хвосте «опросник» у события любого вида), окно пункта с формой в
пульте (вкладка, «красное», строка, история), ряд опросников в форме нового пункта (партия 4), четыре новых
MCP-инструмента, заметки напоминаний (Р12 = 1). Не меняется: пять готовых опросников, запись `feel` / `focus` /
`evening` / `who5`, `evening_done` (`store/journal.py:227`), `load/*`, уже созданные события, штатные вкладки и
«красное» пунктов без формы. Правило окна v2.9 (ROADMAP «Сейчас») цело: формулы и константы не трогаются, записи не
переписываются; при Р13 = 1 «Самочувствие» формы пишется в `wellbeing_log` так же, как сейчас у `feel`
(`web/marks.py:127`). Одно следствие для данных окна — Р7 = 1 (слово «температура» уходит из текста).
**Вне репо:** Влад добавляет в `.claude/settings.json` строку allow `Bash(cat .claude/agents/coach-agenda/checkins.md)`
(партия 2; кабан свои настройки не правит — AGENTS.md). После партии 2 — перезапуск MCP-сервера и новая сессия
тренера. Новых команд CLI нет.
