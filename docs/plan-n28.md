## Суть

**Задача:** в план рабочего дня (`create_day_plan`) всегда ставить два блока разбора инбокса по 20 минут — после завтрака
и после отдыха; задачи из туду в план не вставлять, но возможность поставить задачу у тренера оставить; день размечать
блоками фокуса, а не зоной на всё свободное окно (Р3 = (1)); длина, число и место блоков — по Р11/Р12: два по 60 мин,
по одному за каждым инбоксом (BACKLOG 68, идея Влада 2026-11-10; решения Р1–Р12 2026-11-11).

**Правило:** было — укладка `plan_day`: `training → meals → tasks(до ужина) → tasks(остаток) → focus` (`day_plan.py:203-211`),
`tasks` приходят параметром `create_day_plan(conn, day, tasks, …)` (`:272-275`), тренер собирает их из `coach todo list`
окном (`coach-day.md:11`) → станет — `training → meals → inbox ×2 (не в сб/вс) → tasks(до ужина) → tasks(остаток) → focus`
(Р8 = (1)): инбокс — два якорных блока «Инбокс» kind `task`, категория `work` (Р2 = (2)), 20 мин, первый от конца
поставленного завтрака (нет завтрака — от начала рамки), второй от конца поставленного отдыха (нет отдыха — от номинала
`snack + 15 + 30`) (Р1 = (2), Р10 = (1); на пустом будне 12:00 и 16:15); параметр `tasks` у `create_day_plan` остаётся
(Р5), тренер заполняет его только задачами, которые пользователь назвал сам, туду не показывает и о задачах не спрашивает
(Р7 = (1)). Фокус: было `FOCUS_MIN = 90`, `FOCUS_MAX = 3` (`day_plan.py:68-70`) → станет `FOCUS_MIN = 60`, `FOCUS_MAX = 2`
(Р11: «два блока по 60 мин»); укладка фокуса было `_Layout.focus`: first-fit по `free_slots` до `focus_until`, не больше
`focus_max` (`:173-186`) → станет: по одному блоку после каждого поставленного инбокса — `first_fit` от конца инбокса до
`focus_until`; инбокс не поставлен — от начала рамки; пауза `BREAK_MIN` от предыдущего блока; не больше `focus_max`
(Р12 = (2)). `BREAK_MIN 15`, `FOCUS_UNTIL 19:00`, еда, отдых, `sleep_limits` (на блок меньше → 1 блок, `caution_from`) — без
изменений.
**Поведение:** меняется — (а) в раскладке будня появляются два блока «Инбокс» (пустой будень: 12:00–12:20 и 16:15–16:35) и
за каждым — «Фокус» 60 мин (12:20–13:20, 16:35–17:35) вместо трёх по 90 (измерено); сигнал сна/болезни/WHO-5 → один блок
(утренний), `caution_from 18:00` ничего дополнительно не режет (оба кончаются до 18:00) — измерено; (б) «Инбокс» — задача
`work`: после `coach
event write` и `coach sync` 40 мин/день входят в календарные часы работы (`README.md:76`; в `total` — +0,67 при `W_WORK
1.0`, только если за день нет ручных и экранных часов, `load/overload.py:52-57`), в пульте окно как у задачи («Оценка»,
«Самочувствие», «Срыв» — `web/marks.py:23`); (в) тренер на «спланируй день» не показывает туду и не спрашивает список задач
— окно `AskUserQuestion` остаётся для распорядка утра (`day_start`, `breakfast_at`) и времени тренировки; задачи — только
названные пользователем в запросе или правке («спланируй завтра, отчёт на час»); (г) сб/вс — без инбокса (Р4 = (1)); (д)
сегодня днём (завтрак уже «раньше начала дня») первый инбокс — от «сейчас» (Р10 = (1)). Сводка, snapshot, нагрузка, пульт —
без правок кода.
**Вне репо:** нет. Новых зависимостей нет. После партии — перезапуск MCP-сервера (меняется описание `create_day_plan`).
