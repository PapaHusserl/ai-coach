## Суть

Сейчас текст самочувствия код не читает вовсе: отклонение по самочувствию — только оценка ≤ 2
(`load/deviations.py:34`). Запись «3, горло и насморк» сигнала не даёт; тренер видит текст в сводке
(`snapshot["wellbeing"]`, 7 дней, `mcp_server/snapshot.py:54, :186`), но правила «симптом в тексте → действуй» у него
нет. Шаг добавляет в `find_deviations`:

- партия 1 — признак `symptoms`: слово-симптом из списка в тексте записей самочувствия за день — отклонение при
  любой оценке; порога нет: есть слово — есть сигнал. Плюс правило тренеру о неспецифичных предвестниках (без кода);
- партия 2 (решение Влада Р9 = 2) — признаки «оценка / настроение ниже своей нормы»: сравнение дня с личной нормой
  за прошлые дни. Здесь порог и формула есть — решения Р10–Р15; реакция тренера — как при риске болезни (Р14 = 3).
