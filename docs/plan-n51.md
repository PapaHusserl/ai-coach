## Суть

Гигиена текстов тренера перед Н52, Н53, Н60, которые их правят: освободить место в файлах у порога и заменить
поштучные тесты запаса одним общим.

1. **Сторожа (BACKLOG 161, 196, 168)** — один параметризованный тест запаса по всем файлам `AGENT_LIMITS` и один по
   всем `coach-help/*.md`; поштучные удаляются. Тест «строка 17» ищет строку по содержимому.
2. **Роли (BACKLOG 155, 156)** — место в `coach.md`, `coach-wellbeing.md`, `coach-week.md`; вопрос о тесте на COVID
   текстом в п. 2а — по решению Влада (Р8).
3. **Справка (BACKLOG 162, 166, 193)** — место в оглавлении `coach-help.md`, темах `pult.md`, `food.md`,
   `wellbeing.md`.

**Правило:** было — запас проверяют поштучные тесты вида `AGENT_LIMITS["coach.md"] - size >= 200` (7 файлов роли из
9; нет у `coach-decisions.md`, `coach-onboarding.md`) и `HELP_TOPIC_LIMIT - len(...) >= 200` (7 тем из 26) → станет —
`limit - size >= RESERVE` для каждого имени `AGENT_LIMITS` и каждого `coach-help/*.md`, `RESERVE = 200` в
`tests/text_limits.py`. При Р1 = 3 и Р4 = 1 меняются сами лимиты: было `"coach.md": 16384`, `"coach-help.md": 6144`
и `HELP_INDEX_LIMIT = 6144` → станет `18432`, `8192`, `8192`.

**Поведение:** команды, MCP, пульт — не меняются. Меняется место текста роли и справки: тренер читает вынесенное
отдельным `cat` (перечень — «Развилки»). При Р8 = 1 или 2 — новая фраза тренера в день тяжёлой серии болезни.

**Вне репо:** Влад добавляет строки allow в `.claude/settings.json` (AGENTS.md, «Местные правила»; кабану нельзя) —
по одной на каждый новый файл: при рекомендованных вариантах четыре —
`"Bash(cat .claude/agents/coach-wellbeing/who5.md)",` (Р2), `"Bash(cat .claude/agents/coach-week/done.md)",` (Р3),
`"Bash(cat .claude/agents/coach-help/pult-state.md)",` (Р5), `"Bash(cat .claude/agents/coach-help/food-pult.md)",`
(Р6). Без строки тест allow красный и тренер спросит разрешение на чтение.
