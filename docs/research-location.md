Дата: 2026-11-22. macOS 26.2, Homebrew Python 3.13 (`.venv`), `pyobjc-framework-CoreLocation` 12.2.2 через
`uv run --with`, `pyproject.toml` и `uv.lock` не тронуты. Скрипт: `spikes/location/probe.py`. В выводе — статусы,
коды и секунды; координаты не читались и не печатались. Контекст — `docs/plan-p7.md`, «Разведка CoreLocation»,
«Тесты» → «Спайк», «Открытые вопросы» п. 1.

## Матрица «Спайк»

1. Главный поток, окно и секунды. Метка `ghostty-main` запущена не в отдельном Ghostty, а через `!` в сессии Claude
   Code: Ghostty как отдельный запуск — не проверено. Окно появилось, Влад ответил «Разрешить»; текст окна не
   записан — не проверено. Статус 0 → 3, место за 1.9 с (включая время на ответ Влада, чистое время
   определения места — не проверено).
2. Фоновый поток с `NSRunLoop`: место пришло сразу (0.0 с, прогон 3); окно уже было принято. Первое определение
   места из фонового потока при непринятом окне — не проверено (прогон 3 шёл после разрешения).
3. Сессия `тренер` через `!` и процесс Claude Code: статус общий — после ответа на окно прогоны 3 и 4 из Bash
   оркестратора дали `3` без нового окна. Разрешение держит «Python» (`org.python.python`), а не терминал.
   Отдельный прогон `trener-bang` не делался — не проверено.
   Особое: первый прогон из Claude Code (до ответа на окно) окна не вызвал и дал отказ `kCLErrorDenied` на 2.0 с
   при статусе 0, без таймаута ответа — окно из такого запуска не показывается; после запуска Владом через `!`
   (окно было) всё работает и из Bash оркестратора.
4. Окно не появилось — «Python» в «Службах геолокации» и ручное включение: не проверено (не понадобилось: окно
   появилось при запуске Влада через `!`).
5. Отказ (выключить «Python» в настройках): не проверено — «Решения» п. 58 (Влад не прогонял). Ожидание из
   разведки (`authorizationStatus` 2, код 1) не подтверждено; код 1 в прогоне 1 пришёл при статусе 0, это не отказ
   пользователя.
6. Wi-Fi выключен: не проверено — «Решения» п. 58.

Не проверено сверх матрицы: сохранится ли разрешение после `brew upgrade python@3.13` (путь и подпись меняются).

## Выводы

- Место процессу Homebrew Python macOS 26.2 даёт: после одного «Разрешить» приходит за доли секунды, из главного и
  из фонового потока с `NSRunLoop`, из процессов, запущенных Claude Code. Опасение разведки про фоновый поток не
  подтвердилось.
- Условие: первое разрешение надо дать запуском из интерактивной среды, где окно покажется (`!` в сессии Влада).
  Запуск из процесса Claude Code без окна до разрешения даёт код 1 `denied` при статусе 0 до разрешения.
  Статус 2 при отказе не наблюдался («Решения» п. 58); причина и текст для этого случая — развилка плана.
- Разрешение получает «Python» целиком (риск 2 плана) — подсказка в справке про «Python» в службах геолокации.
- Решение по «Открытым вопросам» п. 1 — за Владом; спайк на сам вопрос «даёт ли macOS место» — зелёный.
  Остаются «не проверено»: отказ, Wi-Fi, обновление Python, отдельный Ghostty, `trener-bang`, первое окно из
  фонового потока, текст окна.
