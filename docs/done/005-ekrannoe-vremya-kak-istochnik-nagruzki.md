# 5. Экранное время как источник нагрузки
status: done
priority: high
updated: 2026-10-27

Источник нагрузки «экранное время» (Влад, 2026-10-11): время в рабочих приложениях, вечер и выходные за экраном, ночной телефон — сигнал выгорания сильнее календаря. Варианты: ActivityWatch (свой трекер на Mac, локальный REST API, категории; iPhone не видит) или системные Biome/knowledgeC (без официального API, нужен Full Disk Access, формат меняется с обновлениями macOS; возможно, есть данные iPhone). В базу — только счётчики часов по категориям, без названий окон. Ресёрч дяди-кабана (2026-10-11): официального API нет (DeviceActivity не выпускает цифры из песочницы); ActivityWatch живой (v0.14.1), без FDA, агрегаты через query API; Biome/knowledgeC — FDA, хрупко, ~4 недели истории, аналог nichtlegacy/screentime. Решение Влада: первая версия — только Mac на ActivityWatch, iPhone (Biome) — позже отдельным спайком; брать после v2.6.
