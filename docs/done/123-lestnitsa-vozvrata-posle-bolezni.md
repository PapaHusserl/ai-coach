# 123. Лестница возврата после болезни
status: done
priority: medium
updated: 2026-11-20

Из ресёрча дяди-кабана 2026-11-15 (чат, просьба Влада). Тренер сам держит паузу, пока сигнал `illness_risk` горит
или есть симптомы, затем ступенчато предлагает возврат: 2 дня пульса покоя и HRV в коридоре без симптомов — неделя
лёгких коротких; после COVID — не меньше 5 дней покоя, весь возврат не меньше 10 дней (BJSM). Температура, ломота,
симптомы в груди — запрет нагрузки вместо правила «выше шеи» (слабая база, риск миокардита). Смежно с BACKLOG 121.
