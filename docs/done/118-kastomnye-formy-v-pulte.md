# 118. Кастомные формы в пульте
status: done
priority: medium
updated: 2026-11-15

Пожелание Влада 2026-11-15: пульт даёт заводить свои формы с полями, а не одну строку текста. Пример —
событие «Температура и самочувствие» раскладывается на поля «Температура» (число, °C) и «Самочувствие»
(шкала). Пользователю — понятная форма, тренеру — готовые поля в базе и MCP, без разбора свободного текста
(сейчас симптомы ищет `load/deviations.py:find_symptoms` по словам). Открыто: кто заводит форму (пользователь
в пульте или тренер), типы полей, связь с событиями и чек-инами, чтение формы тренером, справка coach-help.
