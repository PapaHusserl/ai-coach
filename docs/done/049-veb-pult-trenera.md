# 49. Веб-пульт тренера
status: done
priority: medium
updated: 2026-11-10

Влад, 2026-11-04: веб-морда, чтобы смотреть и обновлять данные тренера без агента. Прототип (артефакт, данные на
04.11 зашиты): https://claude.ai/artifact/BgNnFnbaWDqsy2ASMwvuCE. Что принял Влад по прототипу:
- Главная — план дня из календаря тренера; текущий пункт подсвечен, прогресс-бар: прошло / осталось.
- У пункта окно по его типу: задача — фокус · усталость · усилие одной записью (как `coach focus`), самочувствие,
  срыв; еда — вкладки «Вариант N» с таблицей что-сколько-К-Б-Ж-У и «Итого», «Съел» или своё; отдых, практика,
  тренировка (выполненная — факт Garmin против плана), вечерний чек-ин. Боковых панелей нет.
- Незаполненное прошедшее — красным; прошедшие пункты можно дозаполнить.
- План меняется на ходу: шкала дня, блок тянуть — сдвиг, край — длительность, клик в пустоту — новый пункт.
- Вкладки: Тренировки (неделя план/факт, нагрузка), Еда (кладовая: «− остаток +», ввод +N/−N, списание
  просроченного, добавление; КБЖУ), Состояние (сигналы, тренды).
- В шапке: вес с записью и синхронизация Garmin — вторичные кнопки.
Нового в данных: привязка отметок к пункту плана, «сделал» у практики, пульсовые зоны тренировки. Стек и сервер —
решает архитектор.
