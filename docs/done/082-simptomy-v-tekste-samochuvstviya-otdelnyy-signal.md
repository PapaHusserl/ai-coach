# 82. Симптомы в тексте самочувствия — отдельный сигнал
status: done
priority: high
updated: 2026-11-13

Наблюдение тренера 2026-11-13: «горло», «насморк» в самочувствии при оценке 3 сигналом не считаются (отклонение только
при оценке ≤ 2). Нужно: симптомы в тексте (горло, насморк, температура) — отдельный сигнал независимо от оценки.
