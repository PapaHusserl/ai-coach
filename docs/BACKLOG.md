## 1. Велбинг-коуч
status: idea
priority: high
updated: 2026-10-10

### Суть

Сейчас ai-coach — тренер на данных Garmin: цели, план, нагрузка, питание, добавки. Велбинг-коуч учитывает
жизнь целиком:

- работу и рабочую нагрузку;
- нагрузку вне тренировок;
- хобби;
- отдых;
- общую нагрузку как сумму всего этого.

### Открытые вопросы

- Источники данных о работе: календарь, Kaiten, трекинг времени, ручной дневник?
- Как учитывать хобби и отдых: ручная отметка, календарь, данные Garmin (стресс, Body Battery)?
- Это расширение ai-coach (новые модули) или отдельный слой над ним?
- Что коуч делает с картиной: советует, перестраивает план тренировок, предупреждает о перегрузе?

## 5. Экранное время как источник нагрузки
status: idea
priority: high
updated: 2026-10-11

Источник нагрузки «экранное время» (Влад, 2026-10-11): время в рабочих приложениях, вечер и выходные за экраном, ночной телефон — сигнал выгорания сильнее календаря. Варианты: ActivityWatch (свой трекер на Mac, локальный REST API, категории; iPhone не видит) или системные Biome/knowledgeC (без официального API, нужен Full Disk Access, формат меняется с обновлениями macOS; возможно, есть данные iPhone). В базу — только счётчики часов по категориям, без названий окон. Ресёрч дяди-кабана (2026-10-11): официального API нет (DeviceActivity не выпускает цифры из песочницы); ActivityWatch живой (v0.14.1), без FDA, агрегаты через query API; Biome/knowledgeC — FDA, хрупко, ~4 недели истории, аналог nichtlegacy/screentime. Решение Влада: первая версия — только Mac на ActivityWatch, iPhone (Biome) — позже отдельным спайком; брать после v2.6.

## 7. Силовые упражнения на время (планка)
status: started
priority: medium
updated: 2026-10-19

У силового упражнения вместо повторов может быть длительность (планка, вис, статика): в черновике тренировки (create_draft_workout) — `seconds` вместо `reps` (как у шагов mobility и run/bike/swim), в Garmin JSON — шаг с окончанием по времени (условие `time` в workouts/garmin_json.py уже есть), на странице для телефона (workouts/phone.py) — «60 с» вместо повторов. Источник — Влад, 2026-10-19.
