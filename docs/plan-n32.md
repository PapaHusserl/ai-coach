## Суть

Двенадцать текстов тренера и справки стоят ближе 200 Б к своему лимиту, семь из них — ближе 35 Б: следующая правка
любого из них красит `make check`. Шаг возвращает запас (способ — Р1), попутно чинит то, что из-за нехватки места
откладывалось: перечни отклонений в `coach.md` (BACKLOG 87), описание `get_deviations` (90), имя темы `claude.md` (94).

**Правило** (первый пункт аппрува, зависит от Р1; `tests/text_limits.py` — единственное место лимитов):

- при Р1 = 1 (вынос): значения лимитов не меняются; новое — тест «перечень отклонений `recalc.md` сверен с
  константами `load/deviations.py`» (BACKLOG 87).
- при Р1 = 2 (лимиты): было `"coach.md": 16384`, `"coach-wellbeing.md": 11264`, `"coach-decisions.md": 4096`,
  `SKILL_LIMIT = 3072`, `EVENING_SKILL_LIMIT = 4096`, `HELP_TOPIC_LIMIT = 8192` → станет `18432`, `13312`, `6144`,
  `4096`, `5120`, `10240`.
- при Р1 = 3 (смешанный, рекомендация): было `"coach-decisions.md": 4096`, `SKILL_LIMIT = 3072`,
  `EVENING_SKILL_LIMIT = 4096` → станет `6144`, `4096`, `5120`; `coach.md` 16384, `coach-wellbeing.md` 11264,
  `HELP_TOPIC_LIMIT` 8192 — не меняются, запас им даёт вынос.

**Поведение:** функции тренера (команды, инструменты, шкалы, вопросы) не меняются. Меняется, что тренер держит в
промпте и что читает `cat` по требованию, и на какие темы разбита справка (Р5). Правило окна v2.9 цело: `load/*`
не трогается, только тексты и строка описания MCP.
**Вне репо:** строки allow в `.claude/settings.json` добавляет Влад (AGENTS.md «Местные правила»; так же в П5,
docs/plan-p5.md Р13): замена `Bash(cat .claude/agents/coach-help/claude.md)` на новое имя (Р4) и по строке на каждый
новый файл — число по вариантам в Р1. После партии 2 — перезапуск MCP-сервера (меняется описание инструмента).
