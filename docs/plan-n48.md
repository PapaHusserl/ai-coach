## Партии

**Одна партия.** Обоснование: три пункта не пересекаются по файлам, кода `src/` нет, объём известной части ~250
строк тестов и 4 строки текста — заметно ниже 400; отдельный круг ревью и аудита на каждый пункт стоил бы дороже
самой работы (в П12 круг мамы и свекрови плюс оркестратор — основная статья). Резать есть смысл только хвост,
размер которого до прогона не известен, — он вынесен условной партией 2.

1. **Партия 1 — всё.** Порядок внутри:
   1. Оркестратор — первым делом, на чистом дереве (до красных тестов доебы): mutmut по четырём функциям
      («Тесты», Б), фоном, по `~/.claude/kaban-kb/progony.md`. Причина порядка: mutmut сначала гонит тесты без
      мутантов и на красном дереве не стартует, а тест allow при Р1 = 1 красный до правки Влада.
   2. Доеба: `marks-forms.test.mjs`, `withFormTab` в `forms.test.mjs` (зелёные сразу — код есть; красная проверка —
      ручными мутантами, «Тесты», А); при Р1 = 1 — тесты текстов (красные до кабана и до строки allow).
   3. Кабан: при Р1 = 1 — `coach-day.md`, `coach-day/replan.md`. Кода нет.
   4. Влад: при Р1 = 1 — строка allow.
   5. По отчёту mutmut — доеба: тесты по выжившим, повтор mutmut по тем же именам.
   - На выходе — кабану: `uv run pytest tests/test_skills_day.py tests/test_skills_practices.py` зелёные (кроме
     теста allow до правки Влада); доебе: `node --test "tests/web/*.test.mjs"` и
     `uv run pytest tests/test_agenda_forms.py`; оркестратору: `make check`, повтор mutmut, проверка руками
     («Тесты», Г).
2. **Партия 2 — условная.** Только если по отчёту mutmut тестов по выжившим больше ~100 строк или нужен разбор
   равносильных с правкой `src/`: тогда тесты по мутантам — отдельной партией со своим ревью, а партия 1
