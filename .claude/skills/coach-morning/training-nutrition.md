# Опция: питание к тренировке

Только если на сегодня есть тренировка (в сводке `sport_nutrition_today` или `plan`); иначе скажи, что тренировки нет, и назови добавки дня, если они есть.

1. В сводке `sport_nutrition_today` - коротко: имя, фаза, г/мл, добавки одной строкой. Подробности (заметки, смещение `offset_min`, натрий) - `get_sport_nutrition_for` (date = сегодня).
2. По каждой тренировке: что до (за `offset_min` минут), что во время (г/мл в час), что после. `water_only` = true - тренировка короче 75 минут, во время только вода. `duration_unknown` = true - длительность неизвестна, спроси её у пользователя.
3. Протоколы фиксированные: подстройку под нагрузку и самочувствие говори словами, цифры протокола не меняй. Нет протокола - дай общую рекомендацию с пометкой «оценка» и предложи сохранить протокол (его запишет агент `тренер`: `coach protocol add`).
4. Добавки назови из `supplements` как есть (доза, когда принимать); `taken` = true - уже принята сегодня, остальные назови непринятыми. Журнал за период - `get_supplement_log`. Это не медицинский совет; кофеин и дозы выше заданных не назначай.
5. После прошедшей тренировки предложи отметить добавки графика `after`; после «да» - `uv run coach supplement take "<имя>"` (через агента `тренер`). Больше ничего не записывай в базу.
Длительность неизвестна (`duration_unknown`): протоколы отдаются без фильтра по `min_duration_min` - отбери по названной пользователем длительности.
