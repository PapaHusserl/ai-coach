# Группы продуктов записи еды

В `save_food_nutrition` передай `groups` - список ключей групп, которые есть в записи. Считаем дни с группой за неделю, а не граммы: группа в записи есть, если в ней есть хоть один продукт группы.

- `fish` - рыба и морепродукты
- `red_meat` - красное мясо (говядина, свинина, баранина)
- `poultry` - птица
- `eggs` - яйца
- `dairy` - молочное (молоко, кефир, творог, сыр, йогурт)
- `legumes` - бобовые (фасоль, чечевица, нут, горох)
- `nuts_seeds` - орехи и семена
- `greens` - листовая зелень (салатные листья, шпинат, укроп, петрушка, рукола)
- `vegetables` - овощи (кроме картофеля и зелени)
- `fruit_berries` - фрукты и ягоды
- `whole_grains` - цельные злаки (овсянка, гречка, бурый рис, цельнозерновой хлеб)

Правила:
- Только эти ключи, других нет (субпродуктов нет). `groups` обязателен; нет подходящей группы (вода, пиво, масло, протеин) - передай `[]`.
- Нет состава («салат», «суп», «бутерброд») - спроси состав, как граммы; не ответил - группы не угадывай.
- Рафинированное (белый рис, белый хлеб, макароны) и картофель в `whole_grains` и `vegetables` не входят.
- Составное блюдо - все группы, которые в нём есть.
- Запись по рецепту - группы по составу рецепта.

## Дозапись старым записям

По запросу «дозапиши группы еде за <даты>»: `get_food_without_groups(start, end)`, по каждой записи группы по её тексту и правилам выше, затем `save_food_groups(food_id, groups)`. КБЖУ не пересчитывай.
- Нет подходящей группы (вода, пиво, протеин, масло) - не записывай (пустой список инструмент отклонит), назови такие записи одной строкой.
- Нет состава («мексиканская смесь», «кимчи») - состав не спрашивай, размечай по очевидному и пометь «по догадке».
- `truncated` = true - скажи, что нужен ещё запуск.
- Сразу пиши и покажи итог таблицей: id, дата, текст -> группы.
