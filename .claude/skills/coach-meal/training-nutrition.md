# Питание к тренировке в рационе

Читать только в день тренировки (по `get_plan` она есть в дате рациона). Не медицинский совет.

1. `get_sport_nutrition_for` (date = дата рациона): по каждой тренировке before / during / after, `water_only`, `duration_unknown`, `supplements`.
2. Включи приёмы до и после в рацион ко времени тренировки: до - за `offset_min` минут до начала, после - через `offset_min` минут после конца. Их граммы входят в КБЖУ дня; считай по `coach food`, не на глаз.
3. Во время тренировки (`during`, г/мл в час) - только при длительности от 75 минут; `water_only` = true - только вода. `duration_unknown` = true - спроси длительность.
4. Протокол фиксированный: подстройку под нагрузку говори словами, цифры не меняй. Нет протокола - общая рекомендация с пометкой «оценка» и предложи сохранить протокол (`coach protocol add` - через агента `тренер`).
5. Добавки назови из `supplements` (`taken` = true - уже принята, не повторяй); кофеин и дозы выше заданных не назначай.
Длительность неизвестна (`duration_unknown`): протоколы отдаются без фильтра по `min_duration_min` - отбери по названной пользователем длительности.
