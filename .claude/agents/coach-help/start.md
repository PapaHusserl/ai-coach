# Запуск и данные

Зачем: открыть тренера, подтянуть свежие данные Garmin и понять, где что лежит.

## Вход - `тренер` и `тренер вечер`

- Что это: команда запускает Claude Code с ролью тренера в папке проекта. Установка один раз: `make install-trener` (кладёт ссылку `~/.local/bin/тренер`).
- Как запустить: `тренер` - утренний разговор; `тренер вечер` - вечерний чек-ин вместо утренней сводки (см. `wellbeing.md`).
- Что получу: тренер сразу делает `coach sync`, читает сводку и отвечает сводкой до 20 строк: сон, HRV, Body Battery, readiness, нагрузка CTL/ATL, план на сегодня, факт вчера, цели, вес и еда, нагрузка вне тренировок, курсы и добавки. В конце строка «что умею».
- Первый запуск: пока профиль пуст, тренер сначала проводит опрос (см. `goals-profile.md`).

## Синхронизация - `coach sync`

- Что это: загрузка метрик, активностей и подходов силовой из Garmin и нагрузки (календарь, туду, груминг) в базу. Опция `--days` - за сколько последних дней (по умолчанию 7); подробности: `coach sync --help`.
- Зачем: цифры в сводке берутся из базы, не из Garmin напрямую. Без sync данные устаревают.
- Как запустить: тренер делает sync сам при старте; вручную - `uv run coach sync`.
- Что получу: итоговые строки по Garmin и по нагрузке. Ошибка Garmin нагрузку не прерывает (код выхода 1); нет настройки календаря или экрана - одна строка в итоге, остальное работает.

## Вход в Garmin - `coach login`

- Что это: полный логин Garmin, пароль вводится скрытно.
- Как запустить: только в обычном терминале (не в сессии тренера): `uv run coach login`. Нужен, когда sync пишет, что токены протухли.
- Что получу: токены лежат в `~/.config/ai-coach/garmin` (или `$AI_COACH_GARMIN_DIR`) вне репо. Ошибка 429 - Garmin просит подождать, повтори позже.

## Импорт - `coach import`

- Что это: ручной импорт, если вход в Garmin сломался: файл FIT активности или zip-экспорт Garmin, без сети.
- Как запустить: `coach import <путь>`; для одиночного FIT, если id нет в имени файла, - `--id`. Опции: `coach import --help`.
- Что получу: активности попадают в базу так же, как после sync.

## Статус и экран

- `coach status` - что запланировано и отправлено на часы (подробнее в `training.md`).
- `coach screen` - экранное время из ActivityWatch за день (подробнее в `workload.md`).

## Где что лежит

- База: `~/.local/share/ai-coach/coach.db` (или `$AI_COACH_DB`), вне репо.
- Токены Garmin: `~/.config/ai-coach/garmin`.
- Настройки нагрузки и календаря: `~/.config/ai-coach/workload.toml` (см. `workload.md`).
- Данные тренера в чате идут через MCP `ai-coach`: он читает базу и пишет только черновики. После обновления кода перезапусти `тренер`: сервер не перечитывает код сам.
