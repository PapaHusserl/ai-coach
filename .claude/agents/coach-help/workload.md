# Нагрузка вне тренировок

Зачем: тренер видит общую нагрузку (работа, хобби, вечера, выходные, дела) вместе с тренировками и вовремя замечает подступающий перегруз.

## Откуда берутся данные

- Календарь, туду, груминг: их кладёт `coach sync` (только числа и часы; названия задач в базу не попадают). Календари раскладываются по категориям (работа, личное, хобби, отдых, игнор) в `~/.config/ai-coach/workload.toml`, вне репо. Календарь, которого нет в разметке, в нагрузку не входит, sync напишет его имя. Нет доступа к календарю - разрешить терминалу в настройках macOS и повторить `coach sync`.
- Часы дня из трёх источников, главнее идёт первый: ваши ручные часы из вечернего чек-ина (`coach feel --work --hobby --rest`), затем экран, затем календарь.
- Туду: в базу идут только числа; команды и ведение пунктов - `cat .claude/agents/coach-help/todo.md`.
- Видно в сводке: часы встреч (всего и после 19:00), туду закрыто и открыто, груминг, строка `overload`. Названия встреч тренер называет только на один день и если спросили.

## Экранное время - `coach screen`

- Что это: часы работы, хобби и браузера за день из ActivityWatch, программы-счётчика на вашем компьютере. Нужна секция `[screen]` в `workload.toml`. В базу идут только часы по категориям, названий приложений и окон нет.
- Как запустить: `uv run coach screen [--days N]` (по умолчанию 1 день; до 04:00 это ещё «вчера»). Вечерний чек-ин запускает её сам. `coach sync` читает экран тоже.
- Что получу: часы по категориям за день; вечером тренер предложит записать их как часы работы и хобби. Не настроено или ActivityWatch не отвечает - одна строка и код 1, остальное работает.

## Вызов и помеха

- Что это: второй признак поверх работы (JD-R). Вызов - код, аналитика, задачи вперёд; помеха - согласования, переписка, неясности.
- Как разметить: в `~/.config/ai-coach/workload.toml` (вне репо) `[screen] challenge = [приложения]`, `hindrance = [приложения]` - только из `work` / `meeting` (или с `[screen.title.<приложение>]`), не в обоих сразу. Окна браузера не размечаются.
- Как попросить тренера: «предложи разметку вызов/помеха». Тренер читает конфиг, предлагает блок TOML (созвоны - помеха), вы правите файл сами, затем `uv run coach screen --days 20` - разметка ложится задним числом.
- Что получу: в `get_workload` `screen_challenge_hours`, `screen_hindrance_hours` (часть `screen_work_hours`; null - не размечено), в `coach screen` - «вызов N ч, помехи M ч». Без списков `coach sync` пишет «экран: вызов/помеха не размечены». Тренер пока копит, в нагрузку и сигналы не входит.
- Календарь: рабочая встреча по умолчанию - помеха; вызов - в `[calendar.demand] challenge = [regex на заголовок]` (регистр не важен). Затем `uv run coach sync --days 30`. Поля `challenge_hours`, `hindrance_hours` - части `work_hours`; у события в `events=true` есть `demand`.
- Общая нагрузка `total` и сигналы перегруза (формула, пороги, что делает тренер): `cat .claude/agents/coach-help/overload.md`.

## Недельный обзор - `coach review done`

- Что это: разбор недели по цифрам: нагрузка тренировок и общая, часы работы, вечера, выходные, туду, настроение, стресс, сон, readiness и разница с прошлой неделей.
- Как запустить: в воскресенье (текущая неделя) и понедельник (прошедшая) тренер сам предложит, пока обзора за неё нет; можно сказать «итоги недели». После разговора - `coach review done ["заметка"]`; другая неделя - `--week <понедельник YYYY-MM-DD>`. Опции: `coach review done --help`.
- Что получу: 3-5 строк выводов по трендам и 1-2 предложения на следующую неделю (черновики или слоты). Повторная отметка заменяет заметку, если дана новая. Пока не отмечено, обзор остаётся «пора».

## Инструменты тренера

- `get_workload` (нагрузка вне тренировок по дням), `get_overload` (сигналы перегруза), `get_weekly_review` (цифры по неделям).
