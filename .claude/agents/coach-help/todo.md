# Туду

Зачем: тренер сам ведёт ваш список дел в `~/.claude/todo.json` - тот же файл, что у whats-up. Делегировать записи вам не нужно.

## Команды - `coach todo`

- Что это: пункт с названием, заметкой и состоянием: todo (в списке), doing (в работе), done (сделан), dropped (отброшен).
- Список: `coach todo list` - открытые пункты (id, состояние, название; doing первыми), `coach todo list --all` - вместе с закрытыми (нужно, чтобы найти пункт для `reopen`).
- Добавить: `coach todo add "<название>" [--note "<заметка>"]` - вывод `+ #8 Название`.
- Состояние: `coach todo start <id>` (в работу), `coach todo done <id>` (сделан), `coach todo drop <id>` (отброшен), `coach todo reopen <id>` (вернуть в todo). Разрешено: todo и doing - друг в друга и в done или dropped; из done и dropped - только `reopen`. Вывод `#8 -> done`. Запрещённый переход - ошибка, файл не меняется.
- Править: `coach todo edit <id> [--title "<название>"] [--note "<заметка>"]` - дату не меняет, так что закрытый пункт остаётся в своём дне.

## Как позвать словами

- «добавь в туду ...», «закрой #5», «взял в работу #3», «отбрось #4», «верни #5», «поменяй название #2».
- По слову пользователя тренер выполняет сразу, без переспроса, и показывает строку результата.
- План дня туду только читает, состояние сам не меняет.

## Что в базе

- В базу идут только числа: сколько закрыто за день и сколько открыто (их кладёт `coach sync`). Названия и заметки в базу не попадают.
