# Цели и профиль

Зачем: тренер подбирает нагрузку и питание под ваши цели и ограничения. Без профиля и целей рекомендации будут общими.

## Первый запуск: опрос

- Что это: пока в профиле чего-то не хватает (в том числе нет ни одной цели), `тренер` перед сводкой проводит опрос блоками по 2-3 вопроса и сразу записывает ответы.
- Что спросит: пол, дата рождения, рост, вес, уровень активности вне тренировок; травмы и ограничения; инвентарь и расписание; цель по весу; цели с датами; питание (аллергии, предпочтения) и принимаете ли витамины. То, что уже пришло из Garmin, тренер покажет и спросит «верно?».
- Что получу: в конце тренер показывает итог `coach profile show`. Уровень активности: `sedentary` - сидячая работа, `light` - немного ходьбы, `moderate` - много на ногах, `active` - физический труд.

## Профиль - `coach profile show`, `coach profile set`

- Что это: ваши данные для расчётов: пол, дата рождения, рост, вес, активность, травмы, инвентарь, расписание, цель по весу, питание.
- Как запустить: `uv run coach profile show` - текущие значения с источниками (Garmin или вручную) и то, что не заполнено. Записать: `coach profile set <ключ> "<значение>"`, например `coach profile set schedule "Пн, Ср 19:00; Сб утро"`. Ключи: `sex` (m или f), `birth_date` (YYYY-MM-DD), `height_cm`, `activity_level`, `max_hr`, `injuries`, `limitations`, `equipment`, `schedule`, `diet`, `preferences`, `weight_goal` (`lose`, `keep`, `gain`), `target_weight_kg`, `weekly_rate_kg`, `kcal_target`. В сессии проще сказать тренеру словами.
- Как заполнять: «нет» у травм и аллергий - тоже значение, скажи «нет». Ручное значение главнее данных Garmin; записи только добавляются, история сохраняется.
- Что получу: цели по калориям и белкам тренер берёт из профиля сам; если у расчёта есть допущения, он их назовёт. Травмы и ограничения учитываются во всех рекомендациях.

## Цели - `coach goal add`, `coach goal list`, `coach goal done`, `coach goal cancel`

- Что это: цели гибкие и сочетаются: гонка, результат, вес, привычка. Меняются со временем.
- Как запустить: фраза («добавь цель: пробежать полумарафон до весны») или `coach goal add "<название>" [--kind ...] [--target "..."] [--date YYYY-MM-DD] [--priority N]`. Список: `coach goal list`. Закрыть: `coach goal done <id>` (достигнута), `coach goal cancel <id>` (отменена) - тренер делает это только после вашего «да». Опции: `coach goal add --help`.
- Что получу: цели и приоритеты видны в сводке и учитываются при плане. Конфликт целей решаете вы.

## Фазы

- Что это: периоды плана (например, набор базы, снижение веса). Тренер сам их не меняет: предлагает фазу только по вашему согласию, и в сводке напоминает принять или отклонить предложенную. Перестройку фазы лучше обсуждать отдельным разговором.
- Отдельной команды CLI для фаз нет, работа идёт через тренера.
