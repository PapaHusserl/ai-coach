# Опрос при пустом профиле

Нужен, когда `profile.missing` в сводке не пуст (в том числе `goals` - нет целей). Спрашивай только то, что есть в `missing`: что уже заполнено - не повторяй. Блоками, по 2-3 вопроса за раз; каждый ответ сразу записывай, не копи.

Запись: `uv run coach profile set <ключ> "<значение>"`, цели - `uv run coach goal add "<название>" [--kind ...] [--target ...] [--date YYYY-MM-DD] [--priority N]`. Ошибка команды (неверное значение) - покажи текст ошибки и переспроси.

1. Анкета: пол (`sex` m/f), дата рождения (`birth_date` YYYY-MM-DD), рост (`height_cm`), вес (`uv run coach weight <кг>`, если Garmin не дал), уровень активности вне тренировок (`activity_level`: sedentary - сидячая работа, light - немного ходьбы, moderate - много на ногах, active - физический труд). Если часть данных пришла из Garmin (в сводке `profile.values`) - покажи и спроси «верно?»; поправку записывай как ручное значение.
2. Травмы и ограничения: `injuries` (ответ «нет» - тоже значение, запиши «нет»), `limitations` (необязательно: что нельзя или не хочется).
3. Инвентарь и расписание: `equipment` (что есть: зал, гантели, турник, бассейн, велосипед), `schedule` (в какие дни и во сколько можно тренироваться, например `uv run coach profile set schedule "Пн, Ср 19:00; Сб утро"`; предложи дни из Garmin, если они есть в `profile.values.schedule`). Вело - только сб/вс.
4. Цель по весу: `weight_goal` (lose / keep / gain); для lose и gain - `target_weight_kg` и, если хочет, `weekly_rate_kg`.
5. Цели с датами: гонки, результаты, привычки - по одной `coach goal add`, с датой, если есть.
6. Питание: `diet` (аллергии и запреты; ответ «нет» - тоже значение, запиши «нет») и `preferences` (что любит и не любит). Они не входят в `missing`: спроси, если в `profile.values` их нет.

В конце выполни `uv run coach profile show` и покажи результат. Дальше продолжай обычный порядок разговора.
