# План дня

Когда: «спланируй день», «спланируй завтра», «план дня», «разложи день», вечерний чек-ин закончен и пользователь сказал «да» на «разложить завтра?». `coach sync` уже сделан при старте: занятые часы календарей и события тренера берутся из базы, календарь читать не нужно.

Что делает `create_day_plan`: за один вызов кладёт в `coach_events` черновики блоков дня вокруг занятого (календари и события тренера, кроме `checkin`). Порядок: тренировка (если дано время), готовка и завтрак, перекус, отдых после перекуса, готовка и ужин, инбокс (два блока «Инбокс» по 20 минут после завтрака и после отдыха, задача `work`, в будни), задачи, фокус; готовка - блок «Готовка» 30 минут вплотную перед завтраком и ужином, сдвигается вместе с едой. Блоки не пересекаются, фокуса в сб/вс и после 19:00 нет, не влезшие до ужина задачи - после ужина. При сигнале сна (`short_night`, `sleep_debt`) или сигнале болезни (`illness_risk`), или низком WHO-5 (`who5_low`) фокус-блоков на один меньше (при сне - ещё и не позже `caution_from`), причина - в `skipped`; рамку дня не сдвигает, «позже начало» - словами пользователя (`day_start`). `focus` и `meal` в нагрузку не входят. В календарь черновики не попадают, пока пользователь не скажет «да».

Занятое время и уже стоящий план проверяй по `get_agenda(date)`, а не по `agenda` в snapshot (там не больше 20 строк). Пользователь называет встречу, которой нет среди занятого, - выполни `uv run coach sync` и повтори вызов.

Порядок разговора:
1. Дата: «завтра» - завтрашняя, иначе сегодняшняя (блоки только после текущего времени). Прошлую дату не планируй.
2. Распорядок утра. Одним окном `AskUserQuestion` спроси, когда встанет и позавтракает (`day_start`, `breakfast_at`), и время тренировки из шага 3. Туду не показывай и о задачах не спрашивай; `tasks` - только задачи, которые пользователь назвал сам («завтра отчёт на час»); категорию `work`, `hobby` или `personal` спроси, если неясна (по умолчанию `work` в будни, `personal` в сб/вс).
3. Тренировка. Есть тренировка плана на этот день (`get_plan`) и её слота нет в `get_agenda(date)` - спроси время в том же окне, это `training_at` (`HH:MM`). Слот уже стоит - не спрашивай, тренер не ставит его второй раз.
4. Вызови `create_day_plan(date, tasks=[{title, minutes, category}] если названы, training_at=...)`. Рамки дня по умолчанию: будни 10:00-00:00, сб/вс 11:00-00:00; пользователь назвал другие - `day_start`, `day_end` (`00:00` - полночь), время еды - `breakfast_at`, `snack_at`, `dinner_at` (`HH:MM`).
5. Покажи таблицу «время - блок» по `drafts` (с `draft_id`), отдельно `skipped` (что не поставлено и почему, одной фразой). Спроси текстом: записать в календарь? В вопросе - краткий план (блоки, тренировка). Заголовки задач короткие, личное в `note` не клади.
6. «Да» - `uv run coach event write <id ...>` по всем `draft_id` (Claude Code спросит ещё раз). Без «да» ничего не записывай. Пользователь не хочет готовить (заготовка есть) - `uv run coach event cancel <id>` блоков «Готовка», остальные - `event write`.
7. «Нет» или правка (другое время, другие задачи, другая рамка) - `uv run coach event cancel <id ...>` по всем показанным черновикам и новый вызов с уточнениями. Повторный вызов без `event cancel` не делай: задача с тем же названием, что уже стоит в agenda, не ставится, а `focus` и `meal` дублировать нельзя.

Ответ `already_planned` (список id): на день план уже есть. Покажи события (`get_agenda`) и предложи разложить заново: черновики - `event cancel`, записанные - `event remove` (только после «да»), затем новый вызов. Пользователь не хочет - оставь как есть.

`drafts` пустой: всё занято или время вышло - скажи одной фразой и предложи другой день или рамку.

Приватность: названия событий лишний раз не пересказывай. Это не медицинский совет.
