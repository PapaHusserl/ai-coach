# План дня

Когда: «спланируй день», «спланируй завтра», «план дня», «разложи день», вечерний чек-ин закончен и пользователь сказал «да» на «разложить завтра?». `coach sync` уже сделан при старте: занятые часы календарей и события тренера берутся из базы, календарь читать не нужно.

Что делает `create_day_plan`: за один вызов кладёт в `coach_events` черновики блоков дня вокруг занятого (календари и события тренера, кроме `checkin`). Порядок: тренировка (если дано время), задачи, завтрак, перекус, отдых после перекуса, ужин, фокус. Блоки не пересекаются, фокуса в сб/вс и после 19:00 нет, вечер после ужина свободен. `focus` и `meal` в нагрузку не входят. В календарь черновики не попадают, пока пользователь не скажет «да».

Занятое время и уже стоящий план проверяй по `get_agenda(date)`, а не по `agenda` в snapshot (там не больше 20 строк). Пользователь называет встречу, которой нет среди занятого, - выполни `uv run coach sync` и повтори вызов.

Порядок разговора:
1. Дата: «завтра» - завтрашняя, иначе сегодняшняя (блоки только после текущего времени). Прошлую дату не планируй.
2. Задачи. Покажи активные пункты туду: `uv run coach todo list` (id, состояние, заголовок). Пусто или нет файла - пользователь называет задачи словами. Одним окном `AskUserQuestion` спроси, какие из них ставить в этот день и сколько минут на каждую (минут в туду нет, их называет пользователь); категорию `work`, `hobby` или `personal` спроси, если неясна (по умолчанию `work` в будни, `personal` в сб/вс). Задач может не быть - тогда только еда, отдых и фокус.
3. Тренировка. Есть тренировка плана на этот день (`get_plan`) и её слота нет в `get_agenda(date)` - спроси время, это `training_at` (`HH:MM`). Слот уже стоит - не спрашивай, тренер не ставит его второй раз.
4. Вызови `create_day_plan(date, tasks=[{title, minutes, category}], training_at=...)`. Рамки дня по умолчанию: будни 10:00-00:00, сб/вс 11:00-00:00; пользователь назвал другие - `day_start`, `day_end` (`00:00` - полночь), время еды - `breakfast_at`, `snack_at`, `dinner_at` (`HH:MM`).
5. Покажи таблицу «время - блок» по `drafts` (с `draft_id`), отдельно `skipped` (что не поставлено и почему, одной фразой). Спроси окном `AskUserQuestion`: записать в календарь? Заголовки задач короткие, личное в `note` не клади.
6. «Да» - `uv run coach event write <id ...>` по всем `draft_id` (Claude Code спросит ещё раз). Без «да» ничего не записывай.
7. «Нет» или правка (другое время, другие задачи, другая рамка) - `uv run coach event cancel <id ...>` по всем показанным черновикам и новый вызов с уточнениями. Повторный вызов без `event cancel` не делай: задача с тем же названием, что уже стоит в agenda, не ставится, а `focus` и `meal` дублировать нельзя.

Ответ `already_planned` (список id): на день план уже есть. Покажи события (`get_agenda`) и предложи разложить заново: черновики - `event cancel`, записанные - `event remove` (только после «да»), затем новый вызов. Пользователь не хочет - оставь как есть.

`drafts` пустой: всё занято или время вышло - скажи одной фразой и предложи другой день или рамку.

Приватность: названия событий лишний раз не пересказывай. Это не медицинский совет.
