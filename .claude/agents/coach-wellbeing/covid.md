COVID: вопрос о тесте, отметка и меры (ссылки из `coach.md`, `coach-wellbeing.md` и `illness.md`)

Поля `get_illness`: `episode.severe` (серия с ознобом, ломотой или температурой от 37,0), `episode.sick_first` (первый день серии), `episode.series_day` (номер дня серии), `episode.covid` (в серии есть отметка), `episode.phase` (`light` - лёгкий режим при COVID). Отметка - только внутри серии болезни; любая мера - предложение.

- Вопрос о тесте: при `episode.severe` = true, `episode.covid` = false и `episode.series_day` не больше 5 спроси «тест на COVID делал?» в первом ответе сессии - в каждой сессии, пока отметки нет (памяти об ответе нет); на «положительный» предложи отметку, после «да» запусти `uv run coach covid`, ошибочную отметку после «да» сними `uv run coach covid --undo`
- Напоминание в начале лёгкой серии: при `episode.severe` = false, `episode.sick_first` - сегодня или вчера, `episode.covid` = false не спрашивай о тесте, а в первом ответе сессии одной строкой скажи: если тест на COVID положительный — скажи: отмечу, будет 5 дней лёгкого режима; ответа не жди, после «да» на отметку запусти `uv run coach covid`
- `episode.covid` = true, `episode.severe` = true (тяжёлая серия): скажи одной строкой дословно, подставив даты (ДД.ММ, день N = `episode.sick_first` + N - 1): «после COVID покой до 5-го дня болезни, возврат не раньше 6-го (<дата 6-го дня>, BJSM 2022), обычный план не раньше 13-го дня (<дата 13-го дня>)»; номера дней и «не раньше» не заменяй на «с <дата>» и «можно начинать», строку на пункты не дели. Покой и возврат читай как в `illness.md`
- `episode.covid` = true, лёгкая серия (`light`): 5 дней от начала болезни только лёгкое, покоя нет (BJSM 2022) - зоны 1-2, без интервалов и тяжёлой силовой, не длиннее 40 минут
