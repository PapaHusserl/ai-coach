Поля дня (раздел «Нагрузка вне тренировок» coach-wellbeing.md)

Поля дня: `work_hours`, `personal_hours`, `hobby_hours`, `rest_hours` - часы встреч календаря (пересечения объединены, отменённые и отклонённые не считаются); `*_evening_hours` - из них после 19:00; `challenge_hours` / `hindrance_hours` - вызов и помехи внутри `work_hours` (встреча без правила - помеха); `weekend` - сб/вс (работа в выходные = `work_hours` при `weekend` = true); `all_day_work` - рабочее событие на весь день (часов не даёт). `todo_closed` - закрыто туду за день, `todo_open` - открыто на дату последнего sync, `grooming_done` / `grooming_pending` - груминг (null - не считалось). `screen_work_hours`, `screen_hobby_hours`, `screen_browser_hours` - часы экрана, `screen_evening_hours` - весь экран после 19:00 (null - нет данных), `screen_challenge_hours` / `screen_hindrance_hours` - вызов и помехи внутри `screen_work_hours` (null - не размечено). `claude_prompts` / `claude_prompts_evening` / `claude_decisions` / `claude_repos` / `claude_switches` - реплики, вопросы-решения, каталоги и переключения в Claude Code за день (наблюдение: в `total` не входят; null - не считалось; в сводке `claude` за 7 дней; имена каталогов - `events=true`). Календарь работу видит слабо: смотри и туду, груминг, экран.
